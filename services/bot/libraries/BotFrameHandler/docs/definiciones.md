# DEFINICIONES

## FRAME

Un "frame" es un objeto o estructura de programación que actúa como un intermediario o interfaz entre el usuario (o sistema) y un sistema o entidad independiente. Este objeto encapsula tanto la información necesaria para entender la entidad con la que se interactúa (como su estado, características y opciones disponibles) como los métodos o acciones que se pueden realizar sobre ella. Al interactuar con un "frame", el usuario puede ejecutar operaciones definidas, modificar estados o extraer información sin necesidad de interactuar directamente con la complejidad interna del sistema o entidad objetivo.

Este concepto permite la abstracción y encapsulamiento de la lógica específica de interacción, facilitando así la modularidad y reusabilidad del código, además de proporcionar una interfaz clara y consistente para los usuarios o sistemas que necesiten interactuar con diferentes entidades o sistemas, independientemente de sus implementaciones internas.

# CONTENEDOR

Un contenedor de frames es una entidad de programación diseñada para agrupar, organizar y administrar múltiples objetos o estructuras de tipo "frame", cada uno representando una interacción específica con sistemas o entidades independientes.

# GALERIA

Una galería es un objeto o estructura de programación que actúa como intermediario entre un usuario o sistema y un contenedor de frames. Su función principal es proporcionar una representación visual o descriptiva de cada frame contenido dentro del contenedor, permitiendo al usuario identificar y seleccionar un frame específico basándose en estas representaciones. La galería facilita la navegación y el acceso a los atributos y métodos de cada frame, haciendo uso de identificadores únicos o representaciones visuales/descriptivas que simplifican la selección y la interacción por parte del usuario.

Características Clave:

- Representación Visual/Descriptiva: Cada frame dentro del contenedor se asocia a una imagen, descripción, o ambos, que lo representa. Esta representación permite a los usuarios o sistemas identificar rápidamente el contenido o la funcionalidad de cada frame sin necesidad de interactuar directamente con él.

- Interacción con Contenedor de Frames: La galería interactúa directamente con el contenedor de frames para extraer las representaciones de cada frame. Esto implica que puede consultar el contenedor para obtener las imágenes, descripciones o cualquier otro tipo de identificador visual o textual que represente a los frames.

- Navegación y Selección: Proporciona mecanismos para que los usuarios naveguen a través de las representaciones de los frames y seleccionen aquel con el que deseen interactuar. Una vez seleccionado, la galería facilita el acceso a los atributos y métodos del frame elegido.

- Agregación de Información Adicional: Además de la representación visual o descriptiva, la galería puede ofrecer información adicional sobre cada frame, como detalles del autor, fecha de creación, y cualquier otro metadato relevante.
